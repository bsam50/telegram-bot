# Jack-style Arabic Bot V3

نسخة مستقلة بنظام صلاحيات موحد ولوحة مطور خاصة.

أهم ما فيها:
- رتب وصلاحيات: مالك أساسي، مالك، منشئ، مدير، أدمن، مميز، عضو.
- رتبتي / الرتب / معلوماتي.
- قوائم الأوامر لا تظهر في المجموعة للعضو العادي.
- خاص المطور: لوحة إدارة للردود العامة والمميزة والمتعددة والألعاب والميزات.
- الهمسات.
- قفل/فتح وتفعيل/تعطيل.
- حظر/طرد/كتم/تقييد وتحذيرات.
- ترحيب وقوانين ورابط.
- بنك وتسلية وزواج ونسبة حب.
- حظر وكتم عام.
- إعدادات قابلة للحفظ في SQLite.

ضع BOT_TOKEN وOWNER_ID وDEV_IDS في Environment Variables.
