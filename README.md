# بوت إدارة القروبات العربي

بوت تيليجرام لإدارة المجموعات بالأوامر العربية وقوائم م1 إلى م6.

## التشغيل
1. ثبّت Python 3.12.
2. `pip install -r requirements.txt`
3. أنشئ متغيرات البيئة:
   - `BOT_TOKEN`
   - `OWNER_ID`
   - `DEV_IDS` (اختياري)
4. شغّل: `python main.py`

## صلاحيات البوت
اجعل البوت مشرفًا في المجموعة مع:
- حذف الرسائل
- حظر/تقييد الأعضاء
- دعوة المستخدمين (لإنشاء رابط)
- إضافة/تعديل المشرفين إذا أردت أوامر رفع الرتب الفعلية

## ملاحظة
"مالك أساسي/مالك/منشئ/مدير/أدمن/مميز" رتب داخل البوت. تيليجرام نفسه لا يسمح للبوت بصنع مالك مجموعة؛ الترقية الفعلية لمشرف تحتاج صلاحية `can_promote_members`.
