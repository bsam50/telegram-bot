# البوت العربي للحماية والإدارة

## التشغيل
1. انسخ `.env.example` إلى `.env`.
2. ضع API_ID و API_HASH و BOT_TOKEN و OWNER_ID.
3. شغّل Redis.
4. ثبّت الحزم: `pip install -r requirements.txt`
5. شغّل: `python main.py`
