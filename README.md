# Botar-like PHP Telegram Bot

هذا المشروع مبني على نفس أسماء أوامر Botar الظاهرة في الصور التي أرسلتها، مع واجهة إعدادات عربية.

## التشغيل
1. افتح `config.php`.
2. ضع توكن البوت في `PUT_BOT_TOKEN_HERE`.
3. ضع معرف المستخدم المطور في `PUT_DEVELOPER_ID_HERE`.
4. ارفع المشروع إلى استضافة PHP تدعم HTTPS وcURL.
5. اجعل `index.php` هو Webhook.
6. ارفع البوت مشرفاً في المجموعة مع صلاحيات الحظر والتقييد وحذف الرسائل.

## ملاحظة
هذا ليس النسخة الأصلية المغلقة من Botar؛ هو تنفيذ مستقل بنفس أسماء الأوامر والوظائف الأساسية الموضحة في README/الصور.
