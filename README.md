# بوت القروبات العربي

هذه نسخة موحدة تحتوي على نظام الرتب والإدارة والقفل/الفتح والإعدادات والردود الديناميكية وأوامر المطور الأساسية.

## التشغيل
pip install -r requirements.txt
ثم ضع BOT_TOKEN و OWNER_ID في Variables في Railway.
شغل:
python main.py

## مهم
لا تضع التوكن داخل GitHub.
يجب أن يكون البوت مشرفًا في المجموعة مع الصلاحيات اللازمة.
